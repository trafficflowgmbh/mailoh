ohmail for macOS — first run
============================

1.  Drag ohmail.app onto the Applications shortcut in this window.

2.  THE FIRST LAUNCH IS BLOCKED — APPROVE IT IN SETTINGS.

    Double-click ohmail.app. macOS holds it on the first launch and says it
    cannot be verified (or that it is damaged). That is expected. Then open
    System Settings › Privacy & Security, scroll down to Security, and click
    "Open Anyway" next to the message about ohmail. Authenticate, confirm once
    more, and it opens — and is remembered from then on.

    Why: this build is UNSIGNED and UN-NOTARIZED. It carries only an ad-hoc
    signature, not an Apple Developer ID, so macOS Gatekeeper holds it on first
    launch. Nothing is damaged — the app has simply not been through Apple's
    notary service. On macOS 15 (Sequoia) the old Control-click → "Open"
    shortcut no longer clears an app that fails notarization; the "Open Anyway"
    button is in System Settings › Privacy & Security instead. Signed, notarized
    builds ship once the ohmail Apple Developer account is in place.

    If macOS still refuses after that:
        xattr -dr com.apple.quarantine /Applications/ohmail.app
    Run that only if you trust where this DMG came from. The honest alternative
    is to build it yourself from source:
        https://github.com/trafficflowhq/ohmail

3.  IT IS SELF-CONTAINED. There is nothing else to install.

    ohmail carries everything it needs to run. You do not need Node, a package
    manager, or any developer tools — open it and it works.

    It keeps itself up to date: when a new version is available it asks before
    installing — it never updates silently. You can also check any time from the
    menu bar, under ohmail > Check for Updates. Updates are cryptographically
    signed, and ohmail installs one only if that signature checks out.

4.  WHAT IT DOES.

    ohmail connects to your own IMAP mail server, mirrors your mailbox to a local
    database on this Mac, and organizes new mail into ohmail/ folders (a Screener
    for first-time senders, and the rest) on the server itself — so the filing is
    visible in any mail client, not just this one. It asks for your mail server
    and password on first launch; the password is sealed into a per-install key in
    your login Keychain and is not written anywhere in the clear.

    Your mail stays on your server. The local mirror is a cache: delete it (or the
    whole app) and nothing on the server is touched — it re-syncs from scratch next
    time. Exactly one copy of ohmail organizes a mailbox at a time.

    To look around WITHOUT connecting a mailbox, launch the fixture preview:
        open -a ohmail --args --demo
    That runs on a small fictional mailbox that ships inside the app — no server,
    no network, no account — so you can judge the interface on its own.

Requires macOS 15 (Sequoia) or newer.
The x86_64 (Intel) build has not been tested on real Intel hardware.
