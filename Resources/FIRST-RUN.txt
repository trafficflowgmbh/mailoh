ohmail for macOS — first run
============================

1.  Drag ohmail.app onto the Applications shortcut in this window.

2.  THE FIRST LAUNCH NEEDS A RIGHT-CLICK.

    In Applications, right-click (or Control-click) ohmail.app and choose
    "Open", then confirm. A normal double-click will be blocked.

    Why: this build is UNSIGNED and UN-NOTARIZED. It carries only an ad-hoc
    signature, not an Apple Developer ID, so macOS Gatekeeper refuses it on a
    plain double-click and says the app "is damaged" or "cannot be opened
    because the developer cannot be verified". Nothing is damaged — the app has
    simply not been through Apple's notary service. Signed, notarized builds
    ship once the ohmail Apple Developer account is in place.

    If macOS still refuses after a right-click → Open:
        xattr -dr com.apple.quarantine /Applications/ohmail.app
    Run that only if you trust where this DMG came from. The honest
    alternative is to build it yourself:
        git clone https://github.com/trafficflowhq/ohmail
        swift build -c release --package-path apps/macos
        swift run  -c release --package-path apps/macos OhMail

3.  WHAT YOU ARE OPENING IS A PREVIEW SHELL, AND IT OPENS WITH A FLAG.

    This build carries no local mail engine, so it cannot mirror and organize a
    mailbox on your own server. Double-click it and it says exactly that, and it
    does not ask you for a mail password it would have no way to use.

    To walk the interface, launch it with the preview flag:

        open -a ohmail --args --demo

    That runs on a small fictional mailbox that ships inside the app — Ohbox,
    Screener, Reads, Receipts, triage piles, search, compose — so you can judge
    the thing itself. In --demo the app makes no network connection at all: the
    mailbox is fictional and nothing is sent.

    Two things this shell can still reach the network for, so you know both: it
    can sign in to ohmail Cloud (the hosted service, over HTTPS to ohmail.app) and
    view a mailbox that service already organizes, and it checks for its own signed
    updates. It contacts nothing else — no telemetry, no analytics. The local sync
    engine, which connects to your own IMAP server and organizes it in place, ships
    in the full download; the repository README tracks that work.

Requires macOS 15 (Sequoia) or newer.
